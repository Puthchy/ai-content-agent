# AI Content Agent

ระบบที่ให้ AI ทำคลิปเล่าเรื่องสั้นแนวตั้ง (YouTube Shorts / IG Reels / TikTok) ให้ตั้งแต่ต้นจนจบ แล้วแนบสินค้า Shopee affiliate ในบางคลิปได้

```
คิดไอเดีย → เขียนสคริปต์ → เสียงพากย์ → ภาพแต่ละฉาก → ประกอบวิดีโอ + ซับ → แคปชัน/แฮชแท็ก
```

รันครั้งหนึ่งจะได้โฟลเดอร์ใน `output/` ที่มีไฟล์เหล่านี้:

| ไฟล์ | คืออะไร |
|---|---|
| `video.mp4` | คลิป 1080×1920 พร้อมเสียงพากย์ |
| `subtitles.srt` | ซับไตเติล นำเข้า CapCut แล้วปรับสไตล์ได้ |
| `post.txt` | ชื่อคลิป แคปชัน แฮชแท็ก และลิงก์ affiliate พร้อมข้อความแจ้ง |
| `script.json` | สคริปต์และคำสั่งสร้างภาพของแต่ละฉาก |
| `scene_XX.png`, `voice.mp3` | ภาพและเสียงที่ใช้ |

## ติดตั้ง

ต้องมี Python 3.10+ และ ffmpeg

```bash
cd ai-content-agent
scripts/setup.sh
```

## เปิดหน้าเว็บ (แนะนำ)

```bash
.venv/bin/python -m agent serve
```

แล้วเปิด http://127.0.0.1:8000 ในเบราว์เซอร์ ในหน้าเว็บทำได้ทุกอย่าง:

- กดสร้างคลิป เลือกจำนวน หรือติ๊กโหมดทดสอบ แล้วดูความคืบหน้าสด
- แก้ตั้งค่าช่อง: ชื่อช่อง แนวเรื่อง น้ำเสียง หมวดสินค้า ความยาวคลิป
- ดูคลิปที่ทำแล้ว อ่านบทพากย์ คัดลอกแคปชัน และดาวน์โหลดวิดีโอ

หมายเหตุ: กดบันทึกตั้งค่าในหน้าเว็บแล้ว คอมเมนต์ใน `config.yaml` จะหายไป แต่ค่าต่าง ๆ ยังอยู่ครบ

## ทดสอบผ่านคำสั่ง (ไม่ต้องมี API key)

```bash
.venv/bin/python -m agent run --dry-run
```

ได้คลิปตัวอย่างที่ภาพเป็นสีพื้นและไม่มีเสียง ไว้เช็กว่าระบบทำงานได้

## ใช้งานจริง

1. ใส่ `ANTHROPIC_API_KEY` ในไฟล์ `.env` (สมัครที่ https://console.anthropic.com)
2. แก้ `config.yaml` ให้ตรงกับช่อง: ชื่อช่อง แนวเรื่อง น้ำเสียงผู้เล่า หมวดสินค้า
3. รัน:

```bash
.venv/bin/python -m agent run --count 3
```

### เสียงพากย์

- ไม่ใส่อะไร → ใช้ gTTS (ฟรี แต่เสียงเหมือนหุ่นยนต์)
- ใส่ `ELEVENLABS_API_KEY` และ `ELEVENLABS_VOICE_ID` → เสียงธรรมชาติกว่ามาก แนะนำสำหรับช่องจริง

### ภาพ

ตอนนี้ตั้งเป็น `placeholder` (ภาพสีพื้น) ต้องเพิ่มผู้ให้บริการสร้างภาพจริงใน `agent/images.py` ก่อนโพสต์จริง หรือเอา `image_prompt` ใน `script.json` ไปสร้างภาพเองใน Midjourney / Kling แล้ววางทับไฟล์ `scene_XX.png`

### Affiliate

ใส่ลิงก์ใน `SHOPEE_AFFILIATE_LINKS` ใน `.env` แล้วตั้ง `affiliate_ratio` ใน `config.yaml` (เช่น 0.3 = ประมาณ 3 ใน 10 คลิป) ระบบจะใส่ข้อความแจ้งว่าเป็นลิงก์ affiliate ให้ทุกครั้ง

## ก่อนโพสต์ ตรวจทุกคลิป

- ฟังเสียงพากย์ว่าอ่านคำไทยถูก
- ดูภาพว่าไม่เพี้ยน ไม่มีตัวอักษรแปลก ๆ
- ติ๊กว่าเป็น "เนื้อหาสังเคราะห์/AI" ตอนอัปโหลด ถ้าภาพดูเหมือนจริง
- ระบบจำชื่อคลิปที่ทำไปแล้วใน `output/history.json` เพื่อไม่ให้ไอเดียซ้ำ อย่าลบไฟล์นี้

## ค่าใช้จ่ายโดยประมาณ

ค่า Claude ต่อคลิปเป็นหลักไม่กี่บาท (เรียก 3 ครั้ง: ไอเดีย, สคริปต์, แคปชัน) ค่าใช้จ่ายหลักจะอยู่ที่เสียงพากย์และภาพถ้าใช้บริการแบบเสียเงิน
